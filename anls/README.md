# anls

Short for **analysis**. Offline, run-by-hand analysis and plotting
scripts (accuracy metrics, ground-truth wrangling, figures) — not part
of the APT application and not on the normal path.

- `gt/` — ground-truth accuracy analysis (OKS/pixel precision tables,
  3D reconstruction, GT project setup).
- `gt2sh/` — ground-truth prep and analysis for the Stephen Huston
  ("SH") datasets (training-data assembly, cropping, kinematics).
- `PlotReachData/` — plotting for the mouse-reach labeling data.

Some of these are historical artifacts and many reference code that no
longer exists and may not run as-is.
